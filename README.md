# GlowHaus Beauty & Skincare Studio

A responsive, static website for a fictional beauty and skincare studio in Cape Town, South Africa.

## Original repository description

GlowHaus is a modern beauty and skincare studio offering treatments, skincare products and online appointment bookings. Its elegant nude and brown design creates a welcoming experience, while interactive features allow customers to shop, book services and manage appointments easily.

## Pages

- `index.html` — studio homepage, treatments, testimonials, and appointment request dialog.
- `contact.html` — contact details, sample opening hours, message form, and fictional studio story.

## Run locally

Open `index.html` in a browser. The site uses external Google Fonts and Unsplash images, so those assets require an internet connection.

## Demo behavior

Appointment requests and contact messages are saved only in the visitor's browser using local storage. They are not delivered to the studio. Appointment requests can create an all-day Google Calendar event for the selected date.

The original repository description above expresses the broader project concept. The current static demo does not include a product shop, customer accounts, or a live booking backend.

The address, phone number, email, opening hours, and studio history are fictional sample details. Replace them before publishing for a real business. Connect a form service or backend before accepting real customer submissions.
